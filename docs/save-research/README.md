# Save research

This folder holds sourced research on how emulators store game saves (not save states), per platform and emulator, as groundwork for sigil's save-unit layouts and for tools that extract one game's save from a shared memory card or filesystem.

The research date is 2026-09-26. Each file records the upstream commits or branch snapshot it cites, and marks unsourced claims UNVERIFIED.

- [nintendo-cart.md](nintendo-cart.md) covers Nintendo cart and disk platforms: NES, FDS, SNES, GB/GBC, GBA, N64, NDS and 3DS.
- [nintendo-disc.md](nintendo-disc.md) covers GameCube, Wii, Wii U and Switch.
- [sega.md](sega.md) covers Sega platforms: SMS, Game Gear, Genesis/MD, Sega CD, 32X, Saturn and Dreamcast.
- [sony.md](sony.md) covers Sony platforms: PS1, PS2, PSP, PS Vita and PS3.
- [variants.md](variants.md) covers when saves carry across regional releases, revisions, fan translations and disc regions.
- [android.md](android.md) covers when save files reach disk on Android after HOME or a process kill.
- [other.md](other.md) covers PCE/PCE-CD, Neo Geo, NGP, Lynx, Jaguar, 3DO, WonderSwan, arcade, DOS, CD-i, Xbox and Xbox 360.

Rows here are research, not yet layout data; a row moves into sigil's layout table only after it is verified with a captured sample.
