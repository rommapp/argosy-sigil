# Nintendo 64

Status: in development
Sigil reads no N64 header, and no layout row names an N64 core yet.

## Save formats

The libretro cores (mupen64plus_next, parallel_n64) keep every save type
in one 0x48800-byte `{stem}.srm`: EEPROM, four controller paks, SRAM and
flash at fixed offsets, with unused regions formatted. mupen64plus
standalone, RMG and simple64 keep one file per type (`.eep`, `.sra`,
`.fla`, and one `.mpk` holding four paks); Project64 keeps one `.mpk`
per controller and grows its files sparsely. The bytes match across
these at fixed offsets, so a converter can slice and pad without loss.
SRAM and flash are stored 32-bit word-swapped.
